## 一、环境准备（一次性，约 5 分钟）

1. **导入项目**：开发者工具 → 导入 → `/Users/samchen/Work/git/MedWorkExchange`，AppID 自动识别（wx31604a391caca372）；
2. **确认环境 ID**：`miniprogram/app.js` 的 `cloudEnv` 已填云开发环境 ID（若之前填过则跳过）；
3. **重跑数据库初始化**：云开发控制台 → 数据库 → 脚本执行 `scripts/init-db.js` 全文，确认输出包含：
   - 新建集合：posts / comments / post_likes / ads / configs / audit_logs
   - `hospital aliases updated` × 3（吉大一院/二院/中日联谊各带别名）
   - `seeded departments dictionary`
4. **补索引**（控制台手动）：

5. **部署云函数**（5 个全部，右键→上传并部署：云端安装依赖）：login / hospital / dealing / application / posts。
