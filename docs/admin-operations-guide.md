# 管理操作手册（OCR 开通 + 管理员权限）

> 更新：2026-09-03。适用于 MedWorkExchange pilot 阶段。

## 一、管理员权限（认证审核 + 举报仲裁共用）

### 权限模型

- `users` 集合的 `is_admin: true` 字段 = 管理员标志
- 控制两个能力：**认证审核**（pages/admin-verify）和**举报仲裁**（report 云函数 adminList/adminResolve）
- 无独立后台系统，入口在小程序「我的 → 身份认证」卡片，管理员点开会多出「认证审核（管理）」选项

### 您自己的权限（已开通 ✓）

2026-09-03 已通过云函数把您当前登录账号设为 `is_admin: true`。重新进入「我的」页即可看到审核入口。

### 给合伙人开通（两种方式任选）

**方式 A：微信开发者工具云数据库控制台（推荐，一次性操作）**

1. 打开微信开发者工具 → 云开发控制台 → 数据库 → `users` 集合
2. 让合伙人先用微信登录一次小程序（任意页面即可，`login.ensure` 会自动建档）
3. 在 users 列表找到他的记录（可按 `nickname` 筛选，或让他把「我的」页昵称发您）
4. 点开该记录 → 添加字段：
   - 字段名：`is_admin`
   - 类型：Boolean
   - 值：`true`
5. 保存。合伙人**杀掉小程序重新打开**（或下拉删除小程序重进），「我的」页即可见审核入口

**方式 B：数据库 JSON 导入（多管理员批量时用）**

云开发控制台 → 数据库 → users → 导入，准备如下格式的一行 JSON（`_id` 必填，先查到他的记录 ID）：

```json
{"_id":"他的记录ID","is_admin":true}
```

导入模式选「Update（更新）」。

### 权限安全说明

- `is_admin` 只能通过数据库控制台或云函数修改，客户端无法伪造（所有 admin 接口都在服务端二次校验）
- 撤销权限：同一位置把值改为 `false` 即可
- 审核操作全部留痕（`verify_material.reviewed_by/reviewed_at`、reports 表 `resolved_by`），可追溯

## 二、开通腾讯云 OCR（激活认证材料自动预审）

> 不开通也能用：认证申请全部进人工审核队列，功能不受阻。开通后「医院名+角色关键词双命中」的材料自动秒过，人工只审灰区和 20% 抽检。

### 步骤

1. **开通服务**：浏览器打开 https://console.cloud.tencent.com/ocr
   - 用您的腾讯云账号登录（没有就注册，实名认证个人级即可）
   - 点击「开通」文字识别服务 → 首次开通自动发放 **1000 次/月免费额度**（通用文字识别，每月 1 号刷新）
2. **创建 API 密钥**：打开 https://console.cloud.tencent.com/cam/capi
   - 点「新建密钥」→ 得到一对 `SecretId` 和 `SecretKey`
   - ⚠️ SecretKey 只显示一次，立即复制保存
   - 建议不用主账号密钥，点「子用户」创建只授权 `QcloudOCRFullAccess` 的子账号密钥（安全最佳实践，图省事用主密钥也能跑）
3. **配置到云函数**：微信开发者工具 → 云开发控制台 → 云函数 → 找到 `verify` → 「配置」→ 环境变量，添加两条：

   | 键 | 值 |
   |---|---|
   | `OCR_SECRET_ID` | 您的 SecretId |
   | `OCR_SECRET_KEY` | 您的 SecretKey |

4. **生效验证**：保存后等 1 分钟，提交一张含医院名的认证材料测试。若 OCR 命中会直接返回「认证材料核验通过，已解锁发布与接单」，且 admin 审核页该记录会带「OCR 自动预审」橙色标记

### 额度与费用

| 项 | 数值 |
|---|---|
| 免费额度 | 通用文字识别 1000 次/月（每月 1 号发放，当月有效） |
| 超出后 | 通用印刷体约 0.1~0.15 元/次（后付费） |
| pilot 消耗预估 | 每人申请 1~3 张材料 → 1000 次 ≈ 每月 300+ 人申请，验证期绰绰有余 |

### 密钥安全注意

- 密钥只配在**云函数环境变量**里（服务端），严禁写进小程序前端代码或提交到 git
- `.gitignore` 已忽略云函数本地敏感配置；若担心泄漏，随时回控制台禁用/更换密钥
